# 한번만 · Hanbeonman

> **한 번의 도움, 다음부터 스스로.**
>
> 자주 하는 일을 말하면, 다음에도 누를 수 있는 내 버튼이 됩니다.

**한번만**은 생활 속 반복 작업을 이름과 조건이 있는 개인 버튼으로 만드는 한국어 웹 서비스입니다. `날씨`처럼 짧게 시작하면 필요한 지역을 묻고, `인천 날씨`처럼 조건을 알려주면 초안을 만듭니다. 초안의 이름과 조건을 고쳐 저장한 뒤 다음부터 버튼을 눌러 실행할 수 있습니다.

2026-09-14 기준 **17가지 생활 작업, 내 버튼 보관함, 설정 편집, 백업과 설정 링크 전달**을 구현하고 통합 검증과 Production의 주요 생성·실행 흐름을 확인했습니다. 현재 버튼은 로그인 없이 해당 브라우저에 저장됩니다. 계정 기반 동기화와 회수 가능한 공유는 후속 출시 범위입니다. 기존 기준선은 [SDD 16절](./SDD.md#16-버전-20-로컬-생활-버튼-구현-기준), 추가 6종의 계약과 검증은 [SDD 17절](./SDD.md#17-버전-21-생활-버튼-6종-확장)에 기록합니다.

## 왜 만드는가

가족에게 날씨 확인이나 파일 정리를 도와줘도 다음번에 같은 설명이 필요할 때가 있습니다. 한번만은 그 도움을 **받는 사람이 자기 조건으로 다시 사용할 수 있는 버튼**으로 남깁니다.

> “엄마, 다음엔 이것만 누르면 돼.”

가족에게 전하는 버튼과 내가 매일 사용하는 버튼 모두 같은 보관함에서 관리합니다. 버스 시간표는 여러 작업 중 하나입니다.

## 지금 만들 수 있는 17가지 버튼

| 작업 | 사용 예 | 실행 결과 |
| --- | --- | --- |
| 날씨 확인 | 인천 날씨 | 현재 상태·기온, 제공되는 체감온도·습도·바람, 오늘 예보와 외출 준비 안내 |
| 고속버스 조회 | 금요일 서울에서 대전 | 저장한 노선·등급·날짜 조건의 공개 시간표와 페이지 이동 |
| 사진 압축 | 사진 긴 변을 1280px로 | 기기 안에서 JPEG 변환 후 ZIP 다운로드 |
| 준비물 체크리스트 | 지갑·휴대폰·열쇠 | 항목 체크, 진행률, 다시 시작 |

| 횟수 기록 | 운동 횟수 세기 | 설정한 수만큼 더하기·빼기·초기화 |

| 레시피 분량 조절 | 2인분을 4인분으로 | 재료별 수량을 비율에 맞춰 계산 |

사진, 체크리스트, 타이머, 계산, 글 정리·복사와 QR 생성은 브라우저에서 처리합니다. 길찾기는 Google 지도로 이동하며 예약 기능은 아닙니다. 날씨와 버스는 서버에서 등록된 공개 API를 조회합니다. 버스 예약·결제·잔여석 조회, 임의 사이트 로그인이나 조작은 제공하지 않습니다.

## 사용 흐름

1. `/create`에서 `날씨`, `타이머`, `버스`처럼 입력하거나 **17가지 생활 작업 템플릿**을 직접 고릅니다. 템플릿은 AI 호출 없이 초안을 엽니다. 목록 검색과 외출·이동, 일상·루틴, 쇼핑·계산, 사진·공유 분류로 도구를 찾을 수 있습니다.
2. 부족한 지역·터미널·시간 등의 질문에 답합니다. 해당 값을 실행할 때마다 묻는 버튼으로 남길 수도 있습니다.
3. 버튼의 이름과 고정 조건, 실행할 때 물어볼 값을 확인하고 저장합니다.
4. **내 버튼**에서 실행합니다. 버스·사진은 저장한 조건을 전용 도구로 전달하고, 길찾기는 지도 서비스로 이동하며 나머지 작업은 보관함의 실행 화면에서 사용합니다.
5. 자주 쓰는 버튼을 즐겨찾기하고, 이름·지역·조건 검색과 작업 종류 필터로 찾습니다. 수정·복제·삭제·마지막 삭제 취소를 지원합니다.
6. 다른 기기로 옮길 때 JSON 백업을 내려받거나 버튼 하나의 설정 링크를 복사합니다. 링크를 받은 사람은 내용을 확인하고 자기 보관함에 저장합니다.

짧은 작업명과 필요한 값의 단계별 입력은 등록된 규칙으로 처리합니다. 더 자유로운 문장은 서버의 Gemini가 17개 작업 계약 안에서 해석합니다. 생성된 버튼을 반복 실행할 때 Gemini를 다시 호출하지 않습니다.

레시피 재료는 `쌀 200 g`, `설탕 1/2 큰술`처럼 한 줄에 이름·양·단위를 적습니다. 잘못된 줄은 오류를 표시하고, 실행 입력을 지우지 않아 바로 수정할 수 있습니다. QR·복사용 글과 재료 목록은 버튼 설정당 200자까지 저장합니다. 단가는 두 상품 모두 같은 단위를 사용하고, 할인 결과는 원 단위로 반올림합니다.

## 저장과 전달

- 보관함은 브라우저 `localStorage`에 **최대 50개**를 저장합니다. 한도를 넘거나 저장이 실패하면 기존 버튼을 지우지 않고 오류를 알립니다.
- 구버전 숫자 ID의 버스 버튼에 출발·도착 정보가 부족하면 필요한 입력을 보충해 복원합니다.
- 백업은 `{ format: "hanbeonman-buttons", version: 1, buttons: [...] }` 구조이며 가져오기·내보내기 모두 **UTF-8 200,000바이트** 이하입니다. 복원 시 기존 버튼을 유지하고 같은 ID는 중복 추가하지 않습니다.
- 백업에는 버튼 설정과 보관함 메타데이터를 담습니다. 사진, 체크 상태, 실행 중인 타이머와 횟수 기록은 별도 실행 데이터이며 백업하지 않습니다.
- 설정 링크는 `/create#button=...`의 URL fragment에 버튼 설정을 넣습니다. 받은 사람의 저장 전 자동 실행은 하지 않습니다. 복사본은 독립적이며 **원격 수정·회수·만료·수신자 신원 확인 기능이 없습니다.** 링크에 들어갈 이름과 조건을 전달 전에 확인할 수 있습니다.
- 같은 브라우저에서 계속 사용할 수 있으며 기기 간 자동 동기화는 아직 연결하지 않았습니다. 브라우저 데이터를 삭제하기 전에는 백업이 필요합니다.

타이머는 종료 시각을 기준으로 남은 시간을 계산하고 다시 열었을 때 복원합니다. 종료 안내는 웹페이지가 열린 동안 표시하며 OS 알람 기능을 대신하지 않습니다.

## 기술 구성

현재 구현은 **TypeScript · Next.js/React · Zod · pnpm workspace · Vercel**을 사용합니다. Gemini는 자연어 해석, TAGO는 고속버스 공개 정보, Open-Meteo는 날씨 조회를 담당합니다. 사진은 브라우저 Canvas와 로컬 ZIP으로 처리합니다. 단위 테스트는 Vitest, 브라우저 테스트는 Playwright로 구성합니다.

Supabase PostgreSQL/Auth를 계정·동기화의 후속 기반으로 설계했고 기존 테이블·RLS 기반을 보관하고 있습니다. 현재 보관함의 저장 경로는 localStorage입니다. Chrome 기록 기반 생성과 서버 발행 버전·공유 토큰은 [SDD](./SDD.md)에 후속 아키텍처로 남겨둡니다.

| 경로 | 역할 |
| --- | --- |
| `apps/web/app/create` | 17개 작업 템플릿, 자연어 생성, 편집기, 보관함·백업·설정 링크, 실행 화면 |
| `apps/web/app/bus`, `photo`, `weather`, `routines` | 버스·사진·날씨·체크리스트·타이머 전용 도구 |
| `packages/contracts` | 작업별 입력 허용 목록·타입·범위와 공통 명세 검증 |
| `packages/connectors` | Gemini 해석, 날씨와 TAGO 요청·응답 정규화 |
| `packages/photo` | 사진 입력 제한·출력 이름·로컬 ZIP 구성 |
| `tests/e2e` | 데스크톱·모바일·320px 브라우저 흐름 검증 |
| `.github/workflows` | 타입·테스트·빌드·비밀값 자동 검사 |

## 로컬 실행과 환경변수

Node.js 24와 pnpm 11.19.0을 사용합니다. 저장소 루트에서 실행합니다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

[로컬 시작 화면](http://localhost:3000)에서 내 버튼으로 이동합니다. `/create`, `/weather`, `/bus`, `/photo`, `/routines`에 직접 접근할 수도 있습니다.

`apps/web/.env.example`을 `apps/web/.env.local`로 복사해 필요한 값을 입력합니다. 17개 템플릿과 기기 내 도구는 외부 키 없이 사용할 수 있습니다.

| 변수 | 용도 |
| --- | --- |
| `GEMINI_API_KEY` | 자유로운 자연어 요청 해석에 사용하는 서버 전용 키 |
| `GEMINI_MODEL` | 현재 기본 모델 `gemini-3.1-flash-lite` |
| `TAGO_SERVICE_KEY` | 공공데이터포털 TAGO 고속버스 공개 조회용 서버 전용 키 |
| `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` | Supabase 공개 연결 설정. 현재 로컬 보관함 사용에는 불필요 |
| `SUPABASE_SECRET_KEY` | Supabase 서버 연결 점검·후속 연동용 서버 전용 키 |

실제 키는 Git·채팅·명령줄 인수·로그에 넣지 않습니다. 로컬은 Git에서 제외된 `.env.local`, 배포는 Vercel 환경변수로 분리하고 서버 키에 `NEXT_PUBLIC_` 접두사를 붙이지 않습니다. 키 변경 후 필요한 환경으로 재배포합니다. 상세 규칙은 [SDD 6.5절](./SDD.md#65-비밀-키-보관과-유출-방지)을 따릅니다.

Vercel 배포 보호로 API에 `401`·`403`이 발생하면 프로젝트의 Deployment Protection과 API 접근 범위를 확인합니다. TAGO 키가 없을 때는 설정 필요 상태를 표시하며 가짜 시간표를 반환하지 않습니다.

## 검증 명령

```sh
pnpm typecheck
pnpm test
pnpm build
pnpm supabase:test
pnpm exec playwright install chromium
pnpm test:e2e
pnpm secrets:check
```

Linux CI에서는 `pnpm exec playwright install --with-deps chromium`으로 시스템 의존성을 함께 설치합니다. 새 clone에서는 다음 명령으로 커밋 전 비밀값 검사를 설치합니다.

```sh
pnpm secrets:install-hooks
pnpm secrets:test
```

기능별 한국어 커밋으로 구현 이력을 남깁니다. 검증 결과와 배포 확인은 [SDD 16절](./SDD.md#16-버전-20-로컬-생활-버튼-구현-기준), 이번 범위와 작업 상태는 [실사용 설계](./docs/plans/2026-09-14-everyday-product-design.md)와 [구현 계획](./docs/superpowers/plans/2026-09-14-everyday-product.md)을 따릅니다.

## 실제 출시까지 남은 일

현재 버전은 반복 사용 가능한 **로컬 생활 버튼**을 구현한 단계입니다. 계정 서비스로 출시하려면 다음 범위를 별도로 완료해야 합니다.

- Supabase Auth 로그인·계정 복구, 소유자 RLS를 적용한 저장·기기 간 동기화와 충돌 처리
- 서버 토큰 기반 공유의 만료·회수와 계정 탈퇴·데이터 삭제
- 분산 환경의 지속적인 API 사용량 제한, 오류 관측과 비용 상한
- 실제 가족 사용자 반복 사용, 공개 조회의 실제 조건별 품질과 새 배포 점검

사업 가설은 가족이 반복해서 쓰는 버튼으로 총 도움 시간을 줄이고 가족 이용권의 가치를 검증하는 것입니다. 독립적인 완료율·반복 사용·설정과 복구에 걸린 시간을 측정하며, 가격과 유료 전환은 아직 검증된 성과가 아닙니다.
