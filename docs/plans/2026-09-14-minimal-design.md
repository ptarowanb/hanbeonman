# 생활 버튼 화면 디자인 정돈 계획

**목표:** 기존 11개 기능을 유지하면서, 반복해서 쓰는 도구에 맞는 차분하고 간결한 화면으로 바꾼다.

**방향:** 밝은 회색 배경과 흰색 표면, 차콜 본문, 절제된 녹색 강조. 굵은 외곽선·기울어진 장식·강한 그림자를 제거하고 1px 구분선과 여백으로 위계를 만든다. 생성 화면은 소개를 축약하고 입력창을 중심에 둔다. 큰 홍보 제목 반복, 알록달록한 기호 대신 일관된 선 아이콘을 사용한다.

**선택 근거:** 어두운 대시보드는 생활 도구의 친근함을 줄이고, 기존 따뜻한 색을 유지한 부분 수정은 현재의 과한 강조를 남긴다. 밝은 중립색 화면을 기준으로 제작한다. 사용자의 기존 승인 없는 기능별 커밋·푸시 지시에 따라 구현까지 진행한다.

## 구현 순서

1. 공통 색·글자·버튼·폼과 서비스 화면의 간격을 정리한다. `globals.css`, `layout.tsx`.
2. 생성·템플릿·보관함에 간결한 제목, 선 아이콘, 정돈된 카드와 상태 표시를 적용한다. `create/page.tsx`, `CreateButtonTool.tsx`, `library.css`, `components/ActionIcon.tsx`.
3. 홈 화면과 날씨·루틴·생활 계산 결과를 같은 기준으로 맞춘다. `page.tsx`, `home.css`, 각 CSS Module.
4. 타입 검사·빌드·기존 브라우저 시나리오로 동작을 확인하고 1440px·393px·320px에서 스크린샷과 가로 넘침, 키보드 포커스를 점검한다.
5. 한글 커밋을 화면별로 나눠 푸시하고 실제 배포 결과를 확인한다.

**검증 기준:** 첫 화면에서 제목과 버튼 생성 입력을 확인할 수 있다. 버튼·입력의 키보드 접근과 기존 라벨이 유지된다. 모바일에서 가로 스크롤이 없다. 사진·버스·날씨 조회와 버튼 생성·저장·편집·실행 흐름은 기존대로 동작한다.

## 구현 및 검증 결과

- 공통 디자인·홈·날씨 및 생활 도구 결과 스타일을 `7bc328c`로 커밋·푸시했다.
- 생성 화면은 반복하던 큰 제목을 줄이고, 입력 패널·11개 선 아이콘·템플릿·보관함을 정리했다. 기존 버튼 이름과 접근 가능한 입력 라벨은 유지한다.
- 전체 Playwright 105개가 PC·모바일·320px 화면에서 통과했다. 타입 검사·프로덕션 빌드·비밀값 검사·diff 검사가 통과했다.
- 홈과 5개 서비스 화면을 1440px·393px·320px에서 확인했고 가로 넘침이 없었다. 생성·저장·체크리스트 실행 결과 스크린샷도 확인했다.
- 독립 검토에서 발견한 입력 예시의 낮은 대비와 저장 카드의 키보드 포커스 잘림을 보완했다. 수정 후 실제 Tab 이동에서 2px 녹색 포커스와 -3px 내부 간격을 확인했고 최종 빌드를 다시 통과했다.
- 새 기능이나 저장 데이터 형식 변경 없이 디자인과 안내 문구만 갱신했다.
