# 한번만 실사용 고도화 설계

사용자가 승인 없이 기능별 구현·한국어 커밋·푸시를 요청한 범위에서 진행한다. 핵심 목표는 `요청 → 검토·수정 → 저장 → 실제 실행 → 재사용·전달`을 끊김 없이 제공하는 것이다.

## 선택한 방향

1. **반복 사용 흐름 완성(채택):** 기존 날씨·버스·사진을 실제 저장 조건으로 실행하고 버튼 관리와 새로운 기기 내 작업을 추가한다. 외부 계정 없이 검증 가능하다.
2. 계정·유료화 우선: 기기 동기화에 유리하지만 반복 작업 자체의 결함이 남는다. 후속 출시 단계로 둔다.
3. 임의 사이트 자동화: 범위와 공급자 호환성 관리가 크므로 등록된 작업 방식으로 확장한다.

## 이번에 제공할 기능

- 내 버튼: 초안·저장 버튼 이름 및 조건 편집, 검색·종류 필터, 즐겨찾기, 복제, 삭제 취소. 저장 실패를 성공으로 표시하지 않는다. 최대 50개에서 자동 삭제하지 않고 용량을 알린다.
- 이동과 전달: 버전이 있는 JSON 백업 및 검증 후 병합. 버튼 하나의 설정 복사 링크는 URL fragment에 넣고 수신자는 검토 후 자기 보관함에 저장한다. 복사본은 원본과 독립적이며 원격 회수나 비공개 인증 기능이 아니다.
- 실행: 버스 출발·도착·등급·요일·날짜를 도구에 전달. 이름이 모호하면 선택을 요구하고 임의로 조회하지 않는다. 사진 크기·품질을 복원하고 사진은 사용자 기기에서 선택한다.
- 새 생활 도구: 체크리스트(항목 체크, 진행률, 다시 시작), 타이머(시작·일시정지·재시작, 종료 시각 기준 남은 시간 계산). 웹페이지를 열어둔 동안 동작하며 OS 백그라운드 알람을 보장하지 않는다.
- 날씨: 현재 상태·체감온도·습도·바람과 오늘 최저/최고·강수확률, 관측/조회 시각, 데이터 근거에 따른 짧은 외출 안내. 기존 응답에 추가 정보가 없어도 조회를 유지한다.
- 진입: 홈에서 내 버튼으로 바로 이동, 종류별 예시와 직접 만들기. 사용자 화면은 한국어 필드명과 작업명으로 표시한다.

## 구조와 계약

기존 Next.js/TypeScript, Zod, Vitest, Playwright를 유지한다. ButtonIntent에 checklist(items: 줄바꿈 구분 문자열)와 timer(minutes: 1~180 정수)를 추가한다. 사진은 maxEdge(320~4096 정수), quality(0.1~1), 버스는 weekday(0~6 정수)를 허용한다. AI 출력·저장·파일·공유 링크는 같은 작업 계약을 검사하고 임의 키·코드는 거부한다.

보관함 저장소는 기존 localStorage 배열을 읽으며 새 메타데이터는 선택적 필드로 호환한다. 입력 파일/링크는 크기·개수·문자열·작업 범위를 검증하고 사용자의 기존 데이터를 덮어쓰지 않는다. 실행 결과는 별도 카드로 표시한다. 날씨 실패 시 재시도할 수 있으며 이전 요청이 새 요청을 덮어쓰지 않도록 한다.

## 완성본의 계정·운영 구조

후속 출시 단계에서는 Supabase Auth로 계정을 확인하고 owner_id 기반 RLS로 저장·동기화한다. 로그인 전 로컬 버튼은 사용자가 선택해 계정으로 복사하고 UUID 및 updatedAt으로 충돌을 감지한다. 회수 가능한 공유는 별도 서버 토큰·만료 정책과 발행 버전을 이용한다. 이번 설정 복사 링크와 구분한다.

공개 출시 판정에는 계정 복구·탈퇴와 데이터 삭제, 지속 저장소 기반 API 사용량 제한, 오류 관측·비용 상한, 실제 가족 사용자 반복 사용 검증을 포함한다. 구현되지 않은 항목을 완료라고 표시하지 않는다.

## 수용 기준

1. 인천 날씨를 생성·이름 수정·저장·실행하고 새로고침 후 복원한다.
2. 버스 생성 조건과 사진 압축 조건이 실행 도구에 반영된다.
3. 체크리스트와 타이머를 생성하고 각각 체크/진행 및 일시정지/종료를 확인한다.
4. 검색·즐겨찾기·복제·삭제 취소를 수행하고 백업을 새 브라우저에 복원한다.
5. 설정 링크는 수신자 저장 전에 자동 실행되지 않는다. 잘못된 링크/백업이 기존 데이터를 손상시키지 않는다.
6. 320px·모바일·데스크톱에서 키보드로 조작 가능하고 가로 넘침이 없다.
7. 단위·브라우저·타입·빌드·비밀값 검사 후 기능별 한국어 커밋과 푸시, 배포 확인을 수행한다.
