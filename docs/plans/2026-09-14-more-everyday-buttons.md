# 생활 버튼 6종 추가 계획

**목표:** 11종에서 17종으로 확장하고, 저장한 조건으로 생활 작업을 반복 실행한다.

## 추가 기능

| 기능 | 저장하는 조건 | 실행 결과 |
| --- | --- | --- |
| QR코드 만들기 | 텍스트 또는 링크 | 브라우저에서 QR 생성·PNG 다운로드 |
| 길찾기 | 목적지, 선택적 출발지, 이동 수단 | Google 지도 길찾기로 이동 |
| 주소·안내문 복사 | 복사할 글 | 클립보드 복사 및 직접 복사 대안 |
| 할인 계산 | 정가, 할인율 | 최종 금액과 할인 금액 |
| 상품 단가 비교 | 두 상품 가격·수량과 공통 단위 | 같은 기준량으로 단가 비교 |
| 레시피 분량 조절 | 기준·목표 인분과 재료 목록 | 재료 수량을 비율에 따라 계산 |

외부 연결이 필요한 길찾기 외에는 기기 안에서 실행한다. QR 내용은 외부 QR 서비스로 전송하지 않는다. 저장 스키마는 기존 필수 입력/고정 입력 규칙과 백업 형식을 유지한다.

## 작업 순서

1. 계약과 자연어 해석: 허용 작업·입력 범위·후속 질문을 확장하고 기존 11종 회귀를 검사한다.
2. 실행 도구: 계산 함수·QR·복사·지도 URL에 의미 있는 검증 테스트를 먼저 작성하고 구현한다.
3. 생성·보관함: 17종 카탈로그·선 아이콘·실행 연결과 템플릿 검색·분류를 추가한다. 서비스 개수는 카탈로그에서 계산한다.
4. 브라우저: 실제 버튼 생성·저장·실행, QR 다운로드, 복사 차단 대안, 외부 지도 URL, 320px 반응형을 검증한다.
5. README·SDD에 사용 예시와 범위를 반영하고 한글 기능별 커밋으로 푸시·배포한다.

## 완료 기준

- 새 6종도 템플릿 선택·자연어 요청·부족한 정보 입력으로 저장할 수 있다.
- 계산 결과는 0·분수·반올림·잘못된 입력을 처리한다. 수치는 AI가 아닌 검증된 함수로 계산한다.
- 외부 지도는 저장된 출발지·목적지·이동 수단을 URL로 전달한다.
- 기존 버튼과 백업을 유지하고 모바일에서 가로 넘침 없이 실행할 수 있다.
